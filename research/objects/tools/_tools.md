# Hand tools

## Parts

- A **working head** (metal) and a **handle** (wood), joined so the head cannot fly off: the handle passes through a hole in the head and is wedged tight.
- Light from the upper left, as for every object: the top of the head lightest, the shaft lit on its left edge.

## Distinguishing features

- **Tiers.** Farming games upgrade a tool in steps (Stardew Valley: basic, copper, steel, gold, iridium). Each step does the same job in fewer blows. A tier changes the metal, the head's size and shape, and the handle's finish, so it reads at a glance.
